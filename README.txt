Tsz Ching Fan academic website

How to use:
1. Open index.html in your browser to preview the site.
2. To add your photo, put a file named profile.jpg in the assets folder and edit index.html to replace the placeholder box with:
   <img src="assets/profile.jpg" alt="Tsz Ching Fan" style="width:235px; border:1px solid #bbb;">
3. To add your CV, put your PDF in the assets folder and link to it from cv.html.
4. Upload all files to GitHub Pages, Netlify, or your website host.

Files included:
- index.html
- cv.html
- research.html
- teaching.html
- contact.html
- styles.css
- assets/
